First release: Bootstrap 5 widgets for Texaryn. `createBootstrapRegistry()` renders native HTML with Bootstrap classes (`form-control`, `form-select`, `form-check`, `form-label`, `form-text`, `is-invalid`, `invalid-feedback`, `btn`) on top of `@texaryn/react`. The package expects Bootstrap 5.3 CSS on the page and never loads it itself.
