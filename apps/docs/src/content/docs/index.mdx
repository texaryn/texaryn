import { Card, CardGrid } from '@astrojs/starlight/components'

Supports JSON Schema Draft 4, Draft 7, 2019-09 and 2020-12, with automatic dialect detection.
See [JSON Schema support](/texaryn/guides/json-schema-support/) for capabilities and limitations.

<CardGrid>
  <Card title="Schema in, UI out">
    A JSON Schema, TypeBox or Zod schema becomes a projection, a typed UI
    document, then a rendered form. Lists, tables and layouts skip the schema
    as display documents. The schema adapters and runtimes import no
    rendering framework.
  </Card>
  <Card title="One document, many renderers">
    The same document renders through React, Angular, Vue, Svelte, SolidJS or
    Web Components. Switching renderer changes presentation, not state.
  </Card>
  <Card title="Proven, not asserted">
    Every advertised capability carries an executable example, and the build
    fails when one is claimed without a demonstration.
  </Card>
  <Card title="Framework neutral by construction">
    The runtime is plain TypeScript. React is one binding over it rather than
    an assumption baked into the core.
  </Card>
</CardGrid>
