**React · Angular · Vue · Svelte · SolidJS · Web Components**

Build a settings page, an onboarding flow, or a form whose fields change with
the answers. Keep the schema as the data contract and choose how each control
renders.

## Know the compatibility contract

The core, JSON Schema adapter and React binding are at **1.0**. Other packages
version independently and remain below 1.0. Read the [roadmap](/texaryn/roadmap/)
for release status and product direction.

JSON Schema Draft 4, Draft 7, 2019-09 and 2020-12 are supported. Supported
dialects do not mean every keyword generates a control: the
[support guide](/texaryn/guides/json-schema-support/) separates form generation
from validation coverage.
