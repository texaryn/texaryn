title: Choose your packages
description: Pick a schema adapter, framework binding and optional widget integration for your Texaryn application.
---

A form needs three pieces: `@texaryn/core`, a schema adapter, and a framework
binding. Display documents need the core and a binding, without a schema adapter.

## Choose a framework

Start in an application that already has the framework installed. For JSON
Schema forms, install `@texaryn/core` and `@texaryn/schema-json`, then add one
binding from this table.

| Framework | Add this binding | Supported peer version | Setup |
| --- | --- | --- | --- |
| React | `@texaryn/react` | React 18.3 or 19 | [Getting started](/texaryn/start/getting-started/) |
| Angular | `@texaryn/angular` | Angular 20 or newer | [Angular guide](/texaryn/guides/angular/) |
| Vue | `@texaryn/vue` | Vue 3.5 or newer | [Vue guide](/texaryn/guides/vue/) |
| Svelte | `@texaryn/svelte` | Svelte 5.20 or newer | [Svelte guide](/texaryn/guides/svelte/) |
| SolidJS | `@texaryn/solid` | SolidJS 1.9 | [SolidJS guide](/texaryn/guides/solid/) |
| Plain JavaScript | `@texaryn/web-components` | No framework dependency | [Web Components guide](/texaryn/guides/web-components/) |

For example, in a Vue application:

```sh
pnpm add @texaryn/core @texaryn/schema-json @texaryn/vue
```

The bindings observe the same runtime contracts. Their component APIs and
runtime lifetime rules follow their own frameworks; see each setup guide.

## Choose a schema

- **JSON Schema:** use `@texaryn/schema-json`. It supports Draft 4, Draft 7,
  2019-09 and 2020-12. Check [support and limits](/texaryn/guides/json-schema-support/)
  for your keywords and reference patterns.
- **TypeBox:** pass its JSON Schema output to `@texaryn/schema-json`.
  No separate Texaryn TypeBox package is needed.
- **Zod 4:** use `@texaryn/schema-zod` with `zod` instead of installing the
  JSON Schema adapter directly. Zod validates; JSON Schema conversion supplies
  the field projection. [Conversion limits](/texaryn/guides/schema-adapters/#zod-4)
  matter for refinements and transforms.

## Choose a look

Every binding includes default widgets and accepts a custom registry.
React also has [Bootstrap 5](https://www.npmjs.com/package/@texaryn/react-bootstrap)
and [Material UI v9](https://www.npmjs.com/package/@texaryn/react-mui) widget packages.
The [styling guide](/texaryn/guides/custom-styling/) covers their setup and
styling the default React controls with your own CSS.

independently: `@texaryn/core`, `@texaryn/schema-json` and `@texaryn/react` are
at 1.0. The other packages remain below 1.0 and may introduce breaking changes
in minor releases. See the [roadmap](/texaryn/roadmap/#current-status) for the
compatibility contract.
